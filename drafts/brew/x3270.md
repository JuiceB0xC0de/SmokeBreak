# x3270

**TLDR;** A terminal emulator for IBM 3270 mainframe screens, with GUI, curses and headless variants, so a modern desktop can talk to a mainframe over TELNET.

x3270 emulates the IBM 3279 (color) and 3278 (monochrome) terminals. It connects over TELNET and speaks the 3270 data stream, including TN3270E, with optional SSL/TLS through OpenSSL. The result is that a Unix, macOS or Windows machine can sit in front of a mainframe application the way a dedicated terminal once did.

The package is a family of front ends. x3270 is the X window version, c3270 runs in curses on a plain console, and s3270 has no display at all and is meant for scripts that read screens. pr3287 emulates a 3287 printer session. The homepage also mentions IND$FILE file transfer, a pop-up keypad for 3270-specific keys, APL2 and DBCS (Chinese and Japanese) character sets, and scripting and debugging facilities.

The idea underneath is that a 3270 terminal is not a character stream like a Unix tty. The host sends whole screens made of fields, and the terminal sends back the fields that changed. That block-oriented model is why s3270 can work as a screen-scraping tool: a script reads a screen, fills in fields and presses a key. It is a door into how mainframe interactive computing worked, and still works.

The homepage gives no explicit problem statement. It simply presents the tool as a way to reach IBM 3270 applications over TN3270 from Unix, X and Windows machines.

## Install

```
brew install x3270
# You need a TN3270 host to connect to. The brief does not say whether one is bundled or public.
# x3270 needs an X display, so on macOS you will need XQuartz. c3270 works in any terminal.
```

## Try this

```
c3270 --help
```
Prints the options for the curses front end, which runs in an ordinary terminal with no X display.

```
s3270 --help
```
Shows the options for the displayless, scriptable variant used for screen scraping.

```
x3270 --help
```
Lists the options for the X window front end, the full graphical emulator.

## What's unique

It is one of the few open-source emulators covering the whole 3270 family, with TN3270E, IND$FILE and DBCS support. The headless s3270 variant sets it apart from ordinary terminal emulators.

## Caveats

It does not support graphics, the homepage lists no commands to get started, and you need a TN3270 host to connect to for it to do anything.
