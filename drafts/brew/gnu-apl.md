# GNU APL

**TLDR;** A free interpreter for APL, the glyph-heavy array language from the 1960s, where one line of symbols can replace a page of loops.

GNU APL is the GNU project's interpreter for APL. The page describes it as an almost complete implementation of ISO standard 13751 (APL, Extended), with nested arrays, complex numbers, and a shared variable interface. It is maintained by Jürgen Sauermann and is more than 140,000 lines of C++.

APL is an array language. Operations apply to whole arrays at once, and programs are written in a dense notation of special symbols instead of keywords. Typing it needs a keyboard mapping and a font with the glyphs. The page says GNU/Linux handles both well, and the Windows installer maps Right-Alt as the APL key (Right-Alt+A types ⍺).

The interpreter can also be scripted. The project's own home page was generated by a CGI script written in APL, so it is meant for more than toy sessions. The page's own verdict: "APL is fun!"

The idea underneath is thinking in arrays rather than loops. If you have only used conventional languages, this is a different way to express computation, and it is a useful door into the whole family of array languages that followed.

## Install

```
brew install gnu-apl
# Homebrew pulls in GTK and related libraries as dependencies.
# Typing APL glyphs needs a keyboard mapping and a font that supports them.
# To try it without installing: https://trygnuapl.github.io
```

## Try this

```
apl --help
```
Lists the interpreter's command-line options so you can see how to start a session or run a script.

## What's unique

It is a free, GNU-licensed implementation of an ISO-standard APL with nested arrays and complex numbers, and it is usable as a scripting language, since the project's own website runs on APL code.

## Caveats

The page calls the implementation only 'almost' complete against ISO 13751, its footer copyright reads 2014 so recency is unclear, and it says nothing about the Homebrew formula.
