# PC6001VX

**TLDR;** An emulator for NEC's obscure early-1980s PC-6001 home computer line, with a built-in ROM so it boots without any dumps.

PC6001VX emulates the NEC PC-6001 and its relatives: the PC-6001A, PC-6001mk2, PC-6601 and the SR variants. It runs ROM images dumped from real machines, plus tape (P6T, P6, CAS), disk (d88) and expansion ROM images, and gives you a running machine with video and sound. It is a port of Yumitaro's PC6001V, modified to run on Linux and similar systems. The README says the X in the name stands for cross-platform.

The interesting part is the machine itself: a home computer from a Japanese lineage that most Western retro-computing circles never touched. You boot into its BASIC, load programs from emulated cassette tape, and see how a small, odd 8-bit machine worked. The emulator also has a monitor/debugger mode, replay recording and WebM video capture, so you can poke at what the machine is doing.

Two features stand out. The 'Boost Up' tape option watches the BASIC work area and feeds the next tape data as soon as the machine starts waiting, which the README says speeds loading by about 9x on N60 and 5x on N60m. TILT mode tilts the screen, a joke feature the README says was inspired by the 3DS Space Harrier.

The manual is in Japanese, so expect to lean on a translator for the details.

## Install

```
brew install pc6001vx
# Needs ROM dumps from a real PC-6001 series machine (filenames are case-sensitive on non-Windows), or choose the built-in compatible ROM on first launch. A GUI app via Qt.
```

## Try this

```
PC6001VX
```
Launches the emulator. On first launch an error appears, and you can point it at a ROM folder or accept the built-in compatible ROM.

## What's unique

It ships a built-in compatible ROM, so it can boot without original dumps, and it adds oddities like Boost Up tape loading and a screen-tilting joke mode.

## Caveats

The built-in ROM does not match the genuine ROMs everywhere, save states are flagged by the README as very incomplete and can corrupt tape or disk images, and the manual is Japanese only.
