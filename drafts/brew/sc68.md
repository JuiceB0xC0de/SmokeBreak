# sc68

**TLDR;** A player for Atari ST and Amiga soundchip music that ordinary players cannot open, with a command-line tool and a few extras installed by Homebrew.

sc68 plays music originally written for Atari ST and Amiga computers. In the project's words, it "intends to play musics originally designed for Atari ST and Amiga computers." Much of this music is not a recording or a simple module file. It needs custom players, which is why general music players skip it.

The project also keeps an archive of tunes that need those players. It leaves out standard Amiga .mod files: "Do not expect to find any Amigatm modules [.mod] music file, since this file format is already supported by most music player softwares." The scope is the odd material that nothing else handles.

The idea underneath is preservation through emulation. Old machines made sound with specific chips and with code written for those chips, and playing that music faithfully means reproducing how the hardware behaved. That is a way into chiptune history and into how sound engines worked on 1980s and 1990s home computers.

Homebrew installs seven executables: as68, debug68, info68, sc68, sc68-config, sourcer68 and unice68. The pages read for this entry do not describe them. The names suggest an assembler, a debugger, an info tool, a source tool and an unpacker, but that is a guess from the names. The project documents its Winamp and XMMS plugins as the main way to play. It was also ported to the Dreamcast as part of the dcplaya project.

## Install

```
brew install sc68

You will also need some sc68-format music files. The project's archive is the place to look, starting from the homepage.
```

## Try this

```
sc68 --help
```
Lists the player's options, so you can see what it accepts.

```
info68 --help
```
Shows the usage for the info tool, probably for reading track details from a music file.

```
as68 --help
```
Shows the usage for as68, so you can see what it does.

## What's unique

It opens Atari ST and Amiga music formats that most players cannot, and it comes with an archive of tunes that need those custom players. The Homebrew package also ships a set of developer-style tools alongside the player.

## Caveats

The site looks untouched since about 2003, the homepage gives no usage examples, and the docs I read do not describe the command-line tools, so expect to learn them from --help.
