# f3

**TLDR;** Fills a flash drive with checkable pseudorandom data, then reads it back to expose cards that claim far more capacity than they hold.

f3 stands for Fight Flash Fraud, or Fight Fake Flash. Counterfeit USB sticks and SD cards are sold with a controller that reports a big capacity, then silently discards or overwrites data past the real limit. The drive looks fine until the day a file comes back wrong. f3 is a free, open way to find out before that happens.

The basic test is two commands. `f3write` fills the free space on a mounted drive with 1GB files named N.h2w, full of pseudorandom data. `f3read` then reads them back and checks every sector. It reports how many were ok, corrupted, changed or overwritten, plus average read and write speeds. The file format is compatible with H2testw, so results can be cross-checked against that tool.

The interesting idea is that each sector records what it should contain and where it should sit. That lets f3read tell a corrupted sector from one that landed at the wrong address, which is how a fake card that wraps around gives itself away. On Linux, `f3probe` goes further. It works on the raw block device, writes only a small number of blocks, and uses a model of how fake controllers behave (the docs name limbo, wraparound and chain) to estimate the real size quickly. `f3fix` can then make a partition matching the usable size.

## Install

```
brew install f3
# Homebrew installs f3write and f3read only. f3probe, f3brew and f3fix are Linux-only: build with `make extra` (needs libudev and libparted dev packages, and root to run).
# Needs a flash drive or memory card to test.
```

## Try this

```
f3write /media/michel/5EBD-5C80/
```
Fills the mounted drive's free space with 1GB N.h2w test files. Substitute your own mount path.

```
f3read /media/michel/5EBD-5C80/
```
Validates the files and prints counts of ok, corrupted, changed and overwritten sectors, plus speeds.

```
f3read --help
```
Lists the options for the read check.

## What's unique

f3probe estimates the real usable size from a few writes using an explicit model of counterfeit controllers, instead of filling the whole card. The H2testw-compatible file format lets you cross-check results.

## Caveats

f3probe, f3fix and f3brew are Linux-only, f3probe is marked experimental, and the example `--destructive` mode wipes the drive; the docs also say to unplug and replug the drive between write and read to avoid cache hits.
