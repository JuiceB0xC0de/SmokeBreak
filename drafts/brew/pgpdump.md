# pgpdump

**TLDR;** Prints the packet structure inside a PGP file, so you can see how OpenPGP messages, signatures and keys are actually laid out.

pgpdump reads a PGP file, either binary or ASCII-armored, and prints one labelled entry per packet. Each entry shows the tag, length and version, then its fields: signature type, hash and public-key algorithms, creation times, salts, fingerprints and signature bytes.

The homepage explains why it exists: "It's very hard to understand the data structure inside this." A PGP message is Base64-like text between BEGIN and END lines, and decoding that by eye gets you nowhere. pgpdump decodes the armor, walks the packet sequence and prints it in readable form. The homepage example is a signed message from RFC 9580 Appendix A.7, which lists a one-pass signature packet, a literal data packet and a signature packet in order.

The idea underneath is that OpenPGP is a stream of tagged, length-prefixed packets. Once you can see them, keys, signatures and encrypted messages stop being opaque blobs. You can read the spec on one side and real data on the other. It covers OpenPGP (RFC 9580 and RFC 4880), the post-quantum algorithms of RFC 9980, the older PGP version 2 (RFC 1991) and the LibrePGP extensions generated by GnuPG. The first release was in December 1998.

## Install

```
brew install pgpdump
```

## Try this

```
pgpdump --help
```
Prints the usage text and the options the tool accepts.

```
cat sig.pgp
```
Shows an ASCII-armored sample file, the RFC 9580 Appendix A.7 signed message, before it is dumped.

```
pgpdump sig.pgp
```
Prints each packet in the file with its tag, size and fields such as signature type, hash algorithm, public-key algorithm and times.

## What's unique

It has tracked OpenPGP since 1998 and still follows the newest specs, including post-quantum OpenPGP and the GnuPG LibrePGP extensions. It is a practical way to learn the wire format from real data.

## Caveats

It only dumps packets: it does not verify signatures or decrypt anything, and the homepage lists no platform or build details.
