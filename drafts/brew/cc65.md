# cc65

**TLDR;** A full C compiler and assembler toolchain for the 6502 chip, letting you write C that runs on the C64, NES, Apple II and other 8-bit machines.

cc65 is a cross-development suite for 6502-family systems. You write C or assembly on a modern computer and it produces machine code for old hardware. The package bundles a C compiler (cc65), a macro assembler (ca65), a linker (ld65), an archiver (ar65), a simulator (sim65), and object-file tools such as co65, od65 and da65. It also includes utilities like chrcvt65, grc65 and sp65. The cl65 driver wraps the steps together.

The project descends from Ron Cain's Small C compiler, enhanced by James E. Hendrix, and was later moved to modern systems and largely rewritten by Ullrich von Bassewitz. Its README describes it as "a complete cross-development package for 65(C)02 systems."

The door it opens is the idea of a target. The same C source can be built for different machines by swapping the per-machine library and linker configuration. The README says "cc65 has C and runtime library support for many of the old 6502 machines," and that "a generic configuration to adapt cc65 to new targets is also around." Reading how a C runtime gets squeezed onto a chip with an 8-bit accumulator and a tiny stack is a good way to see what C quietly assumes about the machine underneath.

The Homebrew install puts the runtime libraries in the share/cc65 directory under the formula's Cellar path. To run what you build, you need an emulator for the target machine, or the real hardware.

## Install

```
brew install cc65
# Output targets old machines: you need an emulator (e.g. for C64 or NES) or real hardware to run what you build.
```

## Try this

```
cc65 --help
```
Lists the C compiler's options, including how it selects a target and optimization level.

```
cl65 --help
```
Shows the all-in-one driver that compiles, assembles and links in a single step.

```
sim65 --help
```
Shows the bundled 6502 simulator, which runs programs without a target emulator.

## What's unique

It is a whole retro toolchain rather than a lone compiler, covering targets from Apple II and Atari to NES, C64, PC Engine and Commander X16 in one package. It still gains new targets, such as the RP6502 Picocomputer.

## Caveats

Output only runs on retro hardware or an emulator, some contributed targets may be incomplete, and I could not confirm a recent release date.
