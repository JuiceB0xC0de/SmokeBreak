# sng

**TLDR;** Turns a PNG into editable text and compiles it back, so you can read and change every chunk of the file in a text editor.

SNG, short for Scriptable Network Graphics, is a small text language that describes the full contents of a PNG: its header, palette, pixel data and metadata chunks. The `sng` program is both compiler and decompiler. Give it a PNG and it writes SNG text. Give it SNG text and it writes a PNG. The manual says the round trip is meant to be lossless.

An SNG file starts with `#SNG` and then lists chunk blocks such as IHDR, PLTE and tEXt, which mostly map one-to-one onto PNG chunks. The pixel data lives in an IMAGE block, which becomes the IDAT chunk, with interlacing and compression handled for you. Pixels can be written as a string, hex, base64, or P1/P3 PBM/PPM text.

The reason it exists is that graphics editors ignore many obscure ancillary chunks. Showing them as plain text lets you see and change data that normally stays hidden. The README also notes that SNG is easy to generate from scripts, so `sng` can be the last step in a pipeline that produces PNGs programmatically.

The underlying idea is that a binary container format becomes much easier to understand once you can read it as text. Decompile a few images and you learn how PNG is put together. The author is Eric S. Raymond.

## Install

```
brew install sng
```

## Try this

```
sng --help
```
Prints the usage summary for the compiler/decompiler.

```
sng image.png
```
Decompiles the PNG into image.sng, a text file you can open in any editor. Direction is chosen by file extension.

```
sng image.sng
```
Compiles the edited text back into image.png.

## What's unique

It is a lossless text round trip for the whole PNG container, including exotic chunks that editors drop. The same format is meant to be edited by hand and generated by scripts.

## Caveats

The -i option is documented as not working yet, and base64 pixel data only works when every byte is below 64, so it suits small palettes or low bit depths.
