# open62541

**TLDR;** A small C99 implementation of OPC UA, the industrial automation protocol most developers never see, as a library you can read and build a server from.

open62541 is an open source stack for OPC UA (OPC Unified Architecture, also IEC 62541), written in C99. It supplies the pieces for building OPC UA servers and clients, or for adding OPC UA to an application that already exists. It also ships as a single-file distribution, `open62541.c` and `open62541.h`, which can be dropped into a project.

The design keeps the core small. The library in `/src` depends only on C99 standard headers. Platform-specific code sits behind an EventLoop plugin in `/arch`, and other pieces such as crypto and information-model storage are plugin interfaces in `/plugins` with default implementations. Some code is generated from the standard's XML definitions by Python scripts at build time. Encryption can pull in mbedTLS or OpenSSL.

The idea underneath is that a server exposes a tree of typed nodes, and clients browse and read them. The README's example server calls `UA_Server_new`, adds a variable with `UA_Server_addVariableNode`, and runs with `UA_Server_runUntilInterrupt`. A client connects to `opc.tcp://localhost:4840` and reads that node with `UA_Client_readValueAttribute`. That is a short path into a protocol used in automation and almost invisible elsewhere.

The project presents itself as a free, portable way to do OPC UA without proprietary licensing, from embedded systems to cloud servers.

## Install

```
brew install open62541
# This formula installs a library, not a command. You write a small C program and link against it.
# On Debian/Ubuntu: apt install libopen62541-1.4-dev
```

## Try this

```
gcc -std=c99 <server.c> -lopen62541 -o server
```
Compiles an example server source file against the installed library. The example server listens on port 4840 by default.

```
git submodule update --init --recursive
```
After cloning the repository, initializes the submodules needed before configuring a source build with CMake.

## What's unique

It is a small, portable C99 stack under MPLv2, so it can be linked into proprietary software without relicensing that code. The project also lists quality gates: fuzzing through oss-fuzz, Valgrind and sanitizer runs, and zero OPC Foundation CTT errors.

## Caveats

It installs no executables, so you must write C against it; a source build needs CMake and git submodules, and encryption adds mbedTLS or OpenSSL. The 'OPC UA Certified' claim covers one example server built with v1.4, not every use of the library.
