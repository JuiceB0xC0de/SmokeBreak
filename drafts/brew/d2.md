# d2

**TLDR;** D2 is a small declarative language that turns a few lines of text into a rendered diagram, with live reload and a hand-drawn sketch mode.

D2 reads a .d2 file describing shapes, containers, and arrows, and renders it to SVG, PNG, PDF, PPTX, GIF, or ASCII. The smallest useful file is one line: `x -> y -> z`. From there the language adds nesting, variables, imports, and globs so a diagram can be built up and reused like code.

The homepage frames the goal as getting "a mental model from your head onto the screen, then make edits with your team", with no drag-and-drop editor involved. Because the source is plain text, a diagram can live in version control, be reviewed in a diff, and be regenerated by a script.

Under the hood, the file is parsed into a graph, then a layout engine decides where everything goes. Three engines are bundled: dagre by default, elk, and the opt-in tala, which is aimed at software architecture diagrams. The layout step is separate from the language, so you can render the same text with different engines and compare. Sketch mode, LaTeX labels, and fonts are handled by bundled Go ports, so no browser is needed and it can run entirely server-side.

The interesting idea is the split between describing structure and choosing layout. You state what connects to what, and the placement is a swappable algorithm's problem.

## Install

```
brew install d2
```

## Try this

```
echo 'x -> y -> z' > in.d2
```
Writes a minimal one-line D2 source file.

```
d2 --watch in.d2 out.svg
```
Renders in.d2 to out.svg, opens a browser window, and reloads it as you edit the file.

```
d2 layout
```
Lists the bundled layout engines so you can try them with --layout.

## What's unique

It is a real language with variables, imports, and swappable layout engines, not just a box-and-arrow shorthand. The homepage also claims it is the only text-to-diagram language that can produce animated diagrams.

## Caveats

The animation claim is the project's own marketing and unverified, and the tala layout engine is bundled but opt-in.
