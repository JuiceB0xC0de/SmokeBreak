# GNU Smalltalk

**TLDR;** A command-line Smalltalk-80 you can script with, where everything is an object and the whole system lives in a rebuildable image file.

GNU Smalltalk is a free implementation of the Smalltalk-80 language. Its command, `gst`, runs Smalltalk source from files or standard input and prints the results. At the `st>` prompt it echoes the value of each top-level expression, so it works like a REPL for a language most developers have only heard about.

Most Smalltalks are built around a graphical environment you live inside. This one goes the other way. The manual says it emphasizes rapid prototyping over the graphical environment of other Smalltalks, and the homepage calls it "well-versed to scripting tasks and headless processing." You can put a `#! /usr/bin/gst -f` line at the top of a file and run it like any shell script.

Underneath is the Smalltalk idea of an image. The VM runs a binary snapshot, `gst.im`. On startup `gst` checks the image against the kernel source files and rebuilds it if it is stale. So the image is a snapshot you can regenerate from source, not an opaque blob. Even the class reference is generated by a Smalltalk program reading the library source.

The language follows the Blue Book closely, with extensions such as generators built on continuations, namespaces, and a Perl-style regex engine. That makes it a handy way to read about one of the most influential object-oriented designs and then try it in a terminal.

## Install

```
brew install gnu-smalltalk
# No accounts or extra runtimes. The first run builds gst.im from the kernel files.
```

## Try this

```
gst --help
```
Lists the flags for the VM, including the quiet and script options.

```
gst
```
Opens the st> prompt, reading from standard input. Type 8r300. 16rFFFF and it prints the decimal values of octal 300 and hex FFFF. Quit with ObjectMemory quit or Ctrl-d.

```
gst -f file args...
```
Runs a Smalltalk file as a script with arguments. The manual describes it as equivalent to gst -q file -a args...

## What's unique

It treats Smalltalk as a scripting language for the shell and headless use, not only as a graphical image. The image can be rebuilt from the kernel source.

## Caveats

The brief shows no clear release or commit date, so check the project page for current activity; the startup sequence is described as complicated, and the regex engine does not fully support Unicode.
