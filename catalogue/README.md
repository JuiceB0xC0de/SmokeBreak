# Smoke Break: the shelf

1050 things worth a break. Pick a shelf.

## [Quick weird payoffs](quick-weird-payoffs.md)  (46)

Run it, something strange or beautiful happens within a minute. Pictures into sound, bytes into geometry, braille physics, colour chemistry in a pipe.

## [Sound and live coding](sound-and-live-coding.md)  (44)

Make noise, music, or audio structures from the terminal. Sequencers, synths, modem tones, morse, spatial audio, live-coded sound.

## [Take things apart](take-things-apart.md)  (259)

Reverse engineering, binary exploration, watching programs execute, poking at file formats, circuits, firmware, apps.

## [Radio and hardware](radio-and-hardware.md)  (85)

SDR, ISM-band decoding, USB and HID poking, serial, anything that talks to a physical thing. Often needs hardware, tag it.

## [Fundamentals you never look at twice](fundamentals.md)  (178)

Protocols and plumbing that run all day in every house and nobody looks at. UPnP, SOAP, mDNS, ARP, DHCP, DNS internals, TLS handshakes. The entry is a door into the protocol, the tool is the key.

## [Deeper rabbit holes](deeper-rabbit-holes.md)  (175)

Real scientific or mathematical software you can actually run at home. Seismology, particle physics, groundwater, RNA folding, knots, digital evolution. Days-off material.

## [Languages and unusual utilities](languages-and-oddities.md)  (236)

Esoteric or unusual languages, databases with a twist, old-school environments, one-of-a-kind utilities that fit nowhere else.

## [Games](games.md)  (27)

Actual games you play in the terminal. Only the strange or excellent ones.
