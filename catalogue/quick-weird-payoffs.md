# Quick weird payoffs

Run it, something strange or beautiful happens within a minute. Pictures into sound, bytes into geometry, braille physics, colour chemistry in a pipe.

46 entries. [Back to the shelf](README.md)

## quick

- **[aalib](../drafts/brew/aalib.md)**: A 1990s library that draws graphics as ASCII characters on any terminal, with a bundled demo that renders a roaring fire in text.  
  `ancient, ascii, graphics, library, terminal`
- **[ansilove](../drafts/brew/ansilove.md)**: Turns old BBS-era ANSI and ASCII art files into PNG images, using the original DOS and Amiga fonts so they look the way they did on screen.  
  `ansi, artscene, ascii-art, bbs, demoscene, png`
- **[arss](../drafts/brew/arss.md)**: Turns a sound file into a spectrogram image, then turns any image, edited or hand-drawn, back into sound.  
  `audio, image, resynthesis, spectrogram`
- **[astroterm](../drafts/brew/astroterm.md)**: A planetarium in your terminal that draws real star, planet and moon positions for any place and date, and can spin the sky forward in time.  
  `astronomy, simulation, terminal, visual`
- **[base16384](../drafts/brew/base16384.md)**: Encodes any binary file as dense CJK characters in UTF-16BE, a base64 alternative that turns bytes into text that looks like Chinese.  
  `base64, cjk, encoding, unicode, utf-16`
- **[binocle](../drafts/brew/binocle.md)**: A graphical viewer that turns any binary file into a colored pixel grid, so structure and hidden image-like regions show up by eye.  
  `binary, gui, reverse-engineering, visual`
- **[caire](../drafts/brew/caire.md)**: Shrinks an image by repeatedly carving out its least interesting pixel paths, so the subject stays put while the empty space collapses.  
  `algorithms, go, image, seam-carving, visual`
- **[chafa](../drafts/brew/chafa.md)**: Chafa turns images and animated GIFs into Unicode and ANSI art in your terminal, or into Sixel and Kitty graphics where supported.  
  `ansi, images, library, sixel, terminal, unicode`
- **[Chromaprint](../drafts/brew/chromaprint.md)**: Chromaprint turns audio into a compact fingerprint string with one command, the same kind of signature AcoustID uses to recognise songs.  
  `acoustid, audio, ffmpeg, fingerprinting`
- **[codevis](../drafts/brew/codevis.md)**: Renders every source file in a folder into one large syntax-highlighted image, so you can see the shape and size of a codebase at a glance.  
  `code-visualization, images, rust, visual`
- **[ddate](../drafts/brew/ddate.md)**: A tiny C program that converts today's date into the Discordian calendar, with five seasons, odd weekday names and a leap day for Saint Tib.  
  `c, calendar, discordian, oddity`
- **[ditaa](../drafts/brew/ditaa.md)**: Draw boxes and arrows with plain characters in a text file, run ditaa, and get a clean bitmap diagram back.  
  `ascii-art, diagrams, images, java`
- **[Ecoji](../drafts/brew/ecoji.md)**: Ecoji turns any data into a string of emoji and back again, from the command line or a small web page.  
  `cli, emoji, encoding, unicode`
- **[glslViewer](../drafts/brew/glslviewer.md)**: A console tool that renders GLSL shaders in a window and reloads them whenever you save the file, driven by stdin or OSC.  
  `generative, glsl, live-coding, opengl, shaders, visual`
- **[Gource](../drafts/brew/gource.md)**: Gource replays a repository's commit history as an animated tree, with contributors drifting around it as they change files.  
  `generative, git, visual, visualisation`
- **[grex](../drafts/brew/grex.md)**: Give grex example strings and it prints one regular expression that matches exactly those strings, turning the usual regex workflow upside down.  
  `automata, cli, regex, rust`
- **[hqx](../drafts/brew/hqx.md)**: A command-line pixel-art enlarger that scales sprites 2x, 3x or 4x using a hand-built lookup table, the way classic console emulators smoothed their graphics.  
  `emulators, image, pixel-art, upscaling`
- **[lavat](../drafts/brew/lavat.md)**: A terminal lava lamp: metaball blobs drift, merge and split on screen, and you reshape them with single keystrokes while it runs.  
  `generative, metaballs, simulation, tui, visual`
- **[libcaca](../drafts/brew/libcaca.md)**: A text-mode graphics library that draws in coloured characters instead of pixels, with demos like a fire effect and an image-to-ASCII converter.  
  `ancient, ascii-art, graphics, library, terminal`
- **[libsixel](../drafts/brew/libsixel.md)**: Converts images into SIXEL, a 1980s DEC terminal graphics format, so you can cat a picture straight into a compatible terminal window.  
  `graphics, images, retro, sixel, terminal`
- **[linecast](../drafts/brew/linecast.md)**: Seven live terminal apps that draw weather, tides, sun, moon, sky, radar and maps as line art from free public data, with no API keys.  
  `astronomy, maps, python, tides, visual, weather`
- **[Logstalgia](../drafts/brew/logstalgia.md)**: Logstalgia turns a web server access log into a Pong game where each request is a ball and failed requests slip past the paddle.  
  `generative, gui, logs, visual, web`
- **[lucky-commit](../drafts/brew/lucky-commit.md)**: Rewrites your latest git commit so its hash starts with a prefix you pick, by quietly padding the message with invisible whitespace.  
  `git, hashing, opencl, rust, sha1`
- **[mapscii](../drafts/brew/mapscii.md)**: Draws a pannable, zoomable world map in your terminal using Braille characters, and you can try it over telnet with nothing installed.  
  `braille, maps, nodejs, openstreetmap, tui, visual`
- **[msdf-atlas-gen](../drafts/brew/msdf-atlas-gen.md)**: Turns a font file into a packed texture of multi-channel distance fields, so game text stays sharp at any scale.  
  `cli, fonts, graphics, library, signed-distance-fields, textures`
- **[msdfgen](../drafts/brew/msdfgen.md)**: Turns a font glyph or SVG shape into a three-channel distance field texture that keeps sharp corners crisp when a shader scales it up.  
  `cpp, distance-fields, fonts, graphics, shaders`
- **[netlistsvg](../drafts/brew/netlistsvg.md)**: Turns a Yosys JSON netlist into an SVG schematic, so synthesised Verilog redraws itself as gates, wires and registers.  
  `schematics, svg, verilog, visual, yosys`
- **[Netpbm](../drafts/brew/netpbm.md)**: Over 350 tiny command-line programs that convert and transform images through a few plain intermediate formats, a 1990s Unix toolbox that still ships everywhere.  
  `classic, converters, images, pipelines, unix-filters`
- **[Notcurses](../drafts/brew/notcurses.md)**: A terminal graphics library that stacks transparent planes of text and pixels, shipped with demos that play video and show images in your terminal.  
  `kitty, library, sixel, terminal-graphics, tui, video`
- **[potrace](../drafts/brew/potrace.md)**: Potrace traces a bitmap and turns it into smooth, scalable vector curves, the tracer behind much of the open-source graphics world.  
  `graphics, svg, tracing, vector`
- **[ssocr](../drafts/brew/ssocr.md)**: Reads the digits off a photo of a seven-segment display and prints them as text, using plain deterministic image rules instead of machine learning.  
  `c, image-processing, ocr, seven-segment`
- **[ssss](../drafts/brew/ssss.md)**: Split a secret into n shares so any t of them rebuild it and fewer reveal nothing, using Shamir's 1979 scheme from the command line.  
  `cryptography, math, secret-sharing, unix`
- **[svgbob](../drafts/brew/svgbob.md)**: Turns ASCII diagrams drawn with dashes, pipes and plus signs into clean SVG, reading each character in the context of its neighbours.  
  `ascii-art, diagrams, rust, svg`
- **[teip](../drafts/brew/teip.md)**: A Rust filter that tapes over parts of a text stream so an ordinary command like sed, tr or awk only touches the bits you pick.  
  `cli, pipelines, rust, text-processing, unix`
- **[up (the Ultimate Plumber)](../drafts/brew/up.md)**: A terminal UI where you type a shell pipeline and see its output update live, so you can build grep, awk and sort chains against real data.  
  `pipes, shell, tui, unix`
- **[utftex](../drafts/brew/utftex.md)**: Turns TeX-style math into multi-line Unicode text for monospace terminals, so fractions, matrices and Greek letters print in plain output.  
  `math, tex, tui, unicode, visual`
- **[vhs](../drafts/brew/vhs.md)**: Write a plain-text script of typed commands and VHS plays it in a hidden terminal and renders a GIF, so demos can be regenerated like code.  
  `ci, demos, gif, terminal, testing`
- **[VisiData](../drafts/brew/visidata.md)**: A terminal spreadsheet that opens CSV, JSON, SQLite, Excel and more as an interactive grid, with histograms, scatterplots and Python per row.  
  `csv, data, python, spreadsheet, tui`
- **[xplanet](../drafts/brew/xplanet.md)**: Renders a shaded image of Earth, another planet, or the Moon as seen from any chosen place and date, then saves it or sets it as your wallpaper.  
  `astronomy, science, visual, wallpaper`
- **[zfind](../drafts/brew/zfind.md)**: A file finder where you write the filter as a SQL WHERE clause, and it searches inside tar, zip, 7z and rar archives as if they were folders.  
  `archives, cli, find, go, sql`
- **[zint](../drafts/brew/zint.md)**: A barcode generator that turns text into around ninety symbologies, from QR codes and Data Matrix to postal codes with bars of different heights.  
  `barcodes, cli, encoding, images, qr-code`

## afternoon

- **[G'MIC](../drafts/brew/gmic.md)**: A scripting language for image pipelines with over a thousand built-in filters, usable from the shell, GIMP, Krita, or a webcam.  
  `filters, gimp, image-processing, scripting-language, visual`
- **[POV-Ray](../drafts/brew/povray.md)**: A ray tracer from 1991 where you write a text description of a scene and the program renders it as a three-dimensional image.  
  `generative, graphics, old-school, raytracing, visual`
- **[projectM](../drafts/brew/projectm.md)**: An open-source reimplementation of Winamp's Milkdrop visualizer that turns live audio into evolving OpenGL imagery driven by community-made preset files.  
  `audio, generative, milkdrop, opengl, presets, visual`
- **[SeExpr](../drafts/brew/seexpr.md)**: Disney Animation's embeddable expression language for artists, with small demo tools that graph formulas and synthesize images from the command line.  
  `disney, expression-language, generative, graphics, library`
- **[Synfig](../drafts/brew/synfig.md)**: A free, open-source 2D animation system where you set key poses and the software calculates the frames between, with a command-line renderer installed by brew.  
  `animation, rendering, vector, visual`
